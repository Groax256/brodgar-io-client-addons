# Barrel Content

Writes what a barrel holds over every barrel in view — *Water*, *Milk*, *Vinegar* — so a cellar reads at a
glance without opening each one.

## Usage

The labels are on from the start. Everything else is in **Options ▸ AddOns ▸ Barrel Content**:

| Setting | Default |
|---|---|
| Show or hide the labels, and a key to toggle them | shown, no key |
| Label empty barrels "Empty" | off |
| Text colour: white, yellow, orange, green, cyan or pink | white |
| Text size | 11 |
| Dark background behind the text, and how opaque it is | off, 60% |
| Height of the label above the barrel | 15 |

Addon hotkeys start unbound, so nothing is claimed until you assign one, on the settings page or in
**Options ▸ Game ▸ Keybindings ▸ Barrel Content**.

## Notes

- The name is the one the game gives the barrel's contents, so it follows what the barrel shows: filling a
  barrel labels it, emptying it takes the label away (or turns it to *Empty*).
- The label shows what is in the barrel, not how much.

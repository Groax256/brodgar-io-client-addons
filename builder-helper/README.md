# Builder helper

Shows what each building site still needs, floating over the site itself: one line per material with
its icon and a `have/total` count, white while short and green once complete.

## Usage

1. Assign a key in **Options ▸ Game ▸ Keybindings ▸ Builder helper** (suggested: `Ctrl+B`).
2. Right-click a building site to open its build window, or place a new building. The site is
   remembered from then on, and its counts follow the window while it is open.
3. Press the key to show or hide the labels over every remembered site in view.

A site is forgotten once every material is complete, and when the building that replaced it comes into
view with the labels on, or is right-clicked.

## Options

**Options ▸ AddOns ▸ Builder helper**:

- **Show materials over building sites** — the same switch as the key.
- **Hide completed materials** — leave out the materials the site already has all of.
- **Forget all sites** — drop everything remembered.

## Notes

- The counts are what the window showed the last time you had it open. A site someone else fills while
  you are away keeps the old counts until you open it again.
- A build window that was already open when the addon loaded is picked up by right-clicking its site
  and standing still for a few seconds.
